# Adventure Reader

Aplicação web responsiva de demonstração para leitura de histórias originais de aventura, em português.

## Funcionalidades implementadas

- Página inicial e biblioteca de histórias originais de demonstração.
- Pesquisa por título, tema e descrição.
- Filtros por categoria.
- Leitor por capítulos, com navegação anterior/seguinte.
- Ajuste do tamanho do texto e modo escuro.
- Favoritos, marcadores e progresso guardados no armazenamento local do navegador.
- Layout responsivo para computador e telemóvel.

## Executar localmente

```bash
npm install
npm run dev
```

## Importante

Esta versão é um protótipo frontend: ainda não inclui autenticação, base de dados remota, sincronização entre dispositivos nem painel administrativo seguro. Esses recursos devem ser implementados antes de uma publicação com utilizadores reais. As histórias incluídas são originais e de demonstração. A aplicação não é afiliada aos titulares de Tintin; use conteúdo de Tintin apenas quando houver autorização/licença.
